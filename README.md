# Dhanacharya Financial Advisors

A modern, animated website for Dhanacharya Financial Advisors - Your trusted partner for comprehensive financial solutions.

## Features

- Modern UI with Framer Motion animations
- Fully responsive design for all devices
- Interactive service cards with 3D tilt effects
- Animated statistics counters
- Infinite scroll partner carousel
- Testimonials section
- Contact page with form

## Tech Stack

- **Vite** - Fast build tool
- **React** - UI library
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Animations
- **shadcn/ui** - UI components
- **React Router** - Client-side routing

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
